# 진행 기록 계약

기록을 만들거나 재개할 때 [진행 기록 공통 계약](../../../references/progress-record.md)을 먼저 읽는다. 기록 위치와 작성 원칙은 그 문서를 따르고, 남길 내용은 아래로 한다.

| 무엇 | 내용 |
|---|---|
| 범위 | 승인 범위, 명세의 경로·버전·해시, 작업 위치, task baseline과 기존 사용자 변경 |
| 회차 상태 | 계획 회차인지 구현 회차인지, 계획 파일 경로, 현재 revision, 역할별 세션 ID, 판정자별 보고 상태와 그 보고가 나온 revision |
| 검증 목록 | 사례 번호, 보일 수단, 상태(미실행, 보임, 실패, 보일 수 없음), 증거 위치와 revision |
| 결정 | 결정 내용, 출처(사용자·명세, 저장소 사실, 에이전트 선택), 근거, 이견이 있었는지, 계획에서 벗어난 것인지 |
| 열린 것 | 아직 답하지 않은 지적, 사용자 결정 대기 항목과 그것이 막고 있는 부분 |
