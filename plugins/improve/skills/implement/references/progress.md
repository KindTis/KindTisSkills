# 구현 기록 계약

[공통 기록 계약](../../../references/progress-record.md)을 읽고 다음 현재 상태를 남긴다.

- 사용자 승인, 명세 경로·버전·해시, 작업 공간·baseline·기존 사용자 변경.
- 계획 경로·버전, Architect 제출·반영 상태, 계획 검토·검증 준비 결과.
- revision의 실제 대상 식별, 담당자와 검토 중 쓰기 경계.
- 사례별 수단·환경·대상·결과·증거 위치·재사용 여부.
- 코드·시각 판정의 확인 범위·진행·판정·미확인 항목.
- 지적별 상태·결정·출처·근거, 계획 이탈과 사용자 결정 대기·영향.

최종 결과와 유효한 이전 근거의 연결을 남기며, 일부 통과와 전체 완료를 구분한다.
