# 구현 단계 입력과 인계

부모는 [리뷰 공통 계약](../../../references/review-contract.md)과 해당 단계의 자료를 전달한다. 공통 입력은 승인 범위·확정 명세 경로와 해시, 적용 규칙, 작업 위치·baseline·기존 사용자 변경, 대상 계획 버전 또는 revision이다. 역할의 판단·권한은 등록된 설정을 따른다.

| 역할·단계 | 추가 입력 | 단계별 반환 |
|---|---|---|
| Architect | 저장소 사실·부모의 결정 | 계획 문안, 요구별 작업·검증 연결과 담당, 선택 근거·미정. 수정 시 영향받는 작업 |
| Implementer | 검토된 계획·담당 파일/검사·재현 또는 원인 근거 | 변경 파일·선택/계획 이탈, 자체 확인의 대상·명령·결과·증거·미확인 |
| Programmer Reviewer | 계획 또는 baseline 대비 task-owned diff·미추적 파일, 관련 실행 근거 | 요구·변경에 연결된 지적과 최소 보완 범위 |
| Tester 계획 | 계획·요구 사례·영향받는 기존 동작 | 대표 사례별 전제조건·관측값·수단·환경, 사전 확인 결과와 구현 후 확인 시점 |
| Tester 실행 | 검증 목록·대상 상태·기존 실행 근거·시각 검수 대상 | 사례별 명령·관측 결과·증거와 입증한 요구, 실패 원인·미확인, 시각 검수 자료 |

작성 문안의 저장과 대상 상태·쓰기 조정은 부모가 [위임 계약](../../../references/delegation.md)에 따라 맡는다. 판정·지적 상태와 종료는 리뷰 공통 계약을 따른다.
