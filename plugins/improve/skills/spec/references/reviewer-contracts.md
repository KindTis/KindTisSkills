# 명세 단계 입력과 인계

부모는 [리뷰 공통 계약](../../../references/review-contract.md)과 해당 역할의 자료를 전달한다. 공통 입력은 사용자 목표·원문 제약, 승인된 작성·검토 범위, 기준 명세·버전, 관련 저장소 사실과 적용 규칙이다. 역할의 판단·권한은 등록된 설정을 따른다.

| 역할 | 추가 입력 | 단계별 반환 |
|---|---|---|
| Planner | 부모의 지적별 결정 | 적용 가능한 전체 문안 또는 패치, 변경 요약·선택 근거·남은 결정 |
| Planner Reviewer | 검토할 명세 버전과 사용자 흐름 자료 | 목표·흐름에 연결된 지적과 필요한 사례·제약 문안 |
| Programmer Reviewer | 관련 코드·도구·플랫폼 자료 | 구현·판정 가능성의 근거와 필요한 사례·제약 문안 |

부모는 두 축의 결과를 통합해 Planner에게 반영할 결정을 전달하고, 저장한 최종 문안과 diff를 관련 리뷰어에게 보낸다. 판정·지적 상태와 종료는 리뷰 공통 계약을 따른다.
