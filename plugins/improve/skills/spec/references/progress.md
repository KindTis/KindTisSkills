# 명세 기록 계약

[공통 기록 계약](../../../references/progress-record.md)을 읽고 다음 현재 상태를 남긴다.

- 작성·개선·검토만 중 범위, 사용자 목표·승인, 명세 경로·버전·실제 상태, 기존 사용자 변경.
- Planner·리뷰어 식별자, 제출 기준과 반영 대기 문안.
- 축별 확인 범위·진행·판정과 그 대상, 열린 지적·사용자 결정 대기·영향.
- 결정·출처·근거, 주요 에이전트 선택과 이견.
- 사례·제약 통합의 반영 여부와 최종 문안 검토 근거.

미정이나 미확인 범위를 완료로 기록하지 않는다. 명세 승인과 검토 완료를 구분한다.
