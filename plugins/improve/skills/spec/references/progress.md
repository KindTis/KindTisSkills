# 진행 기록 계약

기록을 만들거나 재개할 때 [진행 기록 공통 계약](../../../references/progress-record.md)을 먼저 읽는다. 기록 위치와 작성 원칙은 그 문서를 따르고, 남길 내용은 아래로 한다.

| 무엇 | 내용 |
|---|---|
| 범위 | 개선인지 검토만인지, 명세 경로, 관련 규칙, 기존 사용자 변경 |
| 회차 상태 | 현재 회차와 명세 버전, 축별 리뷰어 세션 ID, 축별 보고 상태(보냄, 지적 있음, 리허설 완료, 종료)와 그 보고가 나온 버전 |
| 산출물 | 리뷰어가 리허설 완료와 함께 낸 사례와 제약(명세에 넣기 전까지) |
| 결정 | 결정 내용, 출처(사용자·명세 원문, 저장소 사실, 에이전트 선택), 근거, 이견이 있었는지 |
| 열린 것 | 아직 답하지 않은 지적, 사용자 결정 대기 항목과 그것이 막고 있는 부분 |
