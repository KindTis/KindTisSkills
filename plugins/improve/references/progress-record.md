# 진행 기록 공통 계약

## Progress record

프로젝트 루트 기준 `docs/reviewing-and-implementing-specs/yyyy-mm-dd-{작업명}.md`에 한국어 Markdown을 UTF-8(BOM 없음)으로 저장한다. 작업 시작의 로컬 날짜와 안전한 작업명을 사용하고 준비 단계에 절대 경로를 남긴다. 구현 계획서와 명세 스냅샷 파일도 같은 폴더에 `yyyy-mm-dd-{작업명}-plan.md`, `yyyy-mm-dd-{작업명}-spec-snapshot.md`로 둔다. 세션 재개·날짜 변경·worktree 이동 후에도 같은 기록을 이어 쓰며 기존 항목을 보존한다. 재개할 때 저장된 현재 상태와 미결 사항을 먼저 확인한다. 이 폴더는 agent 작업용 기록이므로 처음 만들 때 폴더 안에 `*` 한 줄의 `.gitignore`를 둬 저장소 변경과 분리한다.

기록 작성 권한이 승인된 범위에 있을 때 주 에이전트가 Main 판단·필요한 설계 자문과 담당자 결과를 취합해 직접 작성·저장한다. 검토만 요청됐고 파일 작성이 승인되지 않았다면 새 파일을 만들지 말고 검토 결과를 응답으로 인계한다.

짧은 현재 상태 뒤에 결정과 증거를 둔다. 모든 도구 호출 전후에 기록하거나 전체 응답·대화·원시 로그를 복사할 필요는 없다. 회차를 보내기 직전과 결과를 받은 직후에 현재 상태를 갱신하고 재현 가능한 증거를 보존한다. 재개하거나 맥락이 압축된 뒤에는 이 기록부터 읽는다. 뒤늦게 복구한 기록은 출처와 복구 사실을 명시하며 당시 남긴 증거로 가장하지 않는다. 고정 숫자 표를 채우는 것을 완료 기준으로 삼지 않는다.

남길 내용은 각 스킬의 기록 계약이 정한다.
