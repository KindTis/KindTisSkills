# 진행 기록 공통 계약

작성·개선·구현의 현재 상태를 이어받을 수 있게 부모가 기록한다. 검토만 요청됐고 파일 작성 권한이 없으면 응답으로 인계한다.

기본 위치는 프로젝트 루트의 `docs/reviewing-and-implementing-specs/yyyy-mm-dd-{작업명}.md`다. 계획은 같은 위치의 `-plan.md`, 명세의 직전 버전은 `-spec-snapshot.md`로 구분한다. 사용자 지정 위치를 우선하며 기록과 기준 명세의 위치를 혼동하지 않는다. 처음 만드는 agent 기록 폴더에는 `*` 한 줄의 .gitignore를 두고 기존 제외 상태·파일을 보존한다.

범위·기준·담당자·현재 판정·열린 지적·결정·증거 위치를 최신 상태로 갱신한다. 중요한 결정은 출처(사용자·명세, 저장소 사실, 에이전트 선택)와 근거를 보존한다. 원시 실행 경과를 복제하지 않는다. 회차 전달과 결과 반영 때 갱신하고 재개·맥락 압축 후 먼저 읽는다. 뒤늦게 복구한 기록은 출처와 복구 사실을 표시한다.

버전·revision의 실제 대상 식별과 근거 재사용은 [위임 계약](delegation.md)을 따른다. 기록을 만들기 위해 commit하거나 제외 파일을 강제 추적하지 않는다.
