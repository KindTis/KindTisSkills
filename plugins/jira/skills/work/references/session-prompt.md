# 독립 세션 업무 지시

에픽의 하위 이슈마다 만든 독립 세션에 아래 지시를 전달한다. 입력은 확인한 실제 값으로 채운다.

```text
Jira <이슈 Key와 URL>를 처리하라.
저장소: <절대 경로>
기준 명세: <Specification이 지정한 첨부 파일명과 접근 경로>
작업 목표와 완료 기준: <이 티켓의 목표·필수 검증·완료 조건>
선행 코드 기준: <필요한 선행 결과의 참조; 없으면 생략>

다음 문장을 이 세션의 goal로 등록하고 수행하라.
첨부된 명세를 $improve:implement 스킬 지침에 따라 작업한다. 작업은 worktree를 이용해 격리된 공간에서 진행한다

이 독립 세션의 기본 주 에이전트는 Sol6.1/xhigh다. 승인된 범위의 독립 리뷰·구현·재작업·검증을 직접 위임·조정하고 일상 제품 선택·리뷰 조정·일반 실패를 근거로 처리하며 결과 파일과 독립 리뷰·필수 검증 증거로 최종 완료를 판단·처리하라. 완료까지 책임지며 같은 범위의 재작업은 반복 승인 없이 진행하라. 별도 읽기 전용 Advisor Astra/xhigh는 새 설계·중요한 구조 결정이 필요한 착수, Main이 근거로 해결하기 어려운 요구·설계 충돌, 조사 결과 설계 변경·요구 재해석이 필요한 쟁점에만 자문하라. 매 착수·모든 리뷰 조정·실패 자체·일반 환경 오류·명확한 구현 결함·최종 완료에는 필수 호출하지 말고 Advisor 최종 승인 게이트를 두지 마라. 전체 테스트 재심사나 일상적인 테스트 방식·규모·재실행 지휘를 맡기지 마라. Advisor는 파일 수정·자식 생성·담당자 직접 지시를 하지 않는다. 모든 자식 결과는 부모에게 반환하며 새 설계 쟁점 없는 Advisor 재호출을 피하고 가능한 기존 Advisor를 재사용하라. Planner/Programmer Astra/xhigh, Implementer Sol6.1/high, Tester Sol6.1/medium의 업무·권한과 기술 자율성·제품 수정 및 기준 완화 금지를 유지하라. 작업 간 영향·범위 변경·스스로 해결할 수 없는 장애는 에픽 조정 주 에이전트에게 필요한 근거와 판단 요청을 반환하라.

이 티켓의 상태와 댓글은 $jira:status로 관리하라. 에픽 상태는 조정 세션이 담당한다.
```

기존 전용 worktree가 있으면 해당 참조를 덧붙인다. 자동 상속되지 않는 사용자 제약·승인 범위도 필요한 내용만 전달한다. 주 에이전트 `gpt-6.1-sol/xhigh`와 역할별 모델·추론 설정은 세션·자식 생성 설정으로 지정하고 요청값과 실제 관측값을 구분한다.
