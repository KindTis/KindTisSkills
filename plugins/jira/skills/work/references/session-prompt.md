# 독립 세션 업무 지시

에픽의 하위 이슈마다 만든 독립 세션에 아래 지시를 전달한다. 입력은 확인한 실제 값으로 채운다.

```text
Jira <이슈 Key와 URL>를 처리하라.
저장소: <절대 경로>
작업 공간: <사용자가 지시한 브랜치·worktree; 없으면 생략>
기준 명세: <Specification이 지정한 첨부 파일명과 접근 경로>
작업 목표와 완료 기준: <이 티켓의 목표·필수 검증·완료 조건>
선행 코드 기준: <필요한 선행 결과의 참조; 없으면 생략>

다음 문장을 이 세션의 goal로 등록하고 수행하라.
첨부된 명세를 $improve:implement 스킬 지침에 따라 작업한다. 작업은 지시한 작업 공간에서 진행하고, 지시가 없으면 현재 브랜치에서 진행한다

이 세션의 주 에이전트로서 승인된 범위의 리뷰·구현·재작업·검증을 위임·조정하고 완료까지 책임져라. 같은 범위의 재작업은 반복 승인 없이 진행하라. 역할·위임·Advisor 호출은 전역 지침과 $improve:implement를 따르라. 작업 간 영향·범위 변경·스스로 해결할 수 없는 장애는 에픽 조정 주 에이전트에게 필요한 근거와 판단 요청을 반환하라.

이 티켓의 상태와 댓글은 $jira:status로 관리하라. 에픽 상태는 조정 세션이 담당한다.
```

자동 상속되지 않는 사용자 제약·승인 범위도 필요한 내용만 전달한다. 주 에이전트는 세션 기본 설정을, 자식은 등록된 역할 설정을 따른다.
